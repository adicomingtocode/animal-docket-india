# Animal Docket India

A fortnightly digest of animal law in India and the animal advocacy movement — court rulings, government notifications, organisation updates, EA Forum reading, careers and key dates.

## How the site works

- `index.html` is the whole site. It reads the list of issues from `issues/index.json` and loads each issue from `issues/issue-NN.json`.
- To publish a new issue: add `issues/issue-NN.json` (same fields as the earlier issues) and add an entry for it at the end of `issues/index.json`. The site always opens on the highest-numbered issue.
- Link to a specific issue with `#issue-NN` at the end of the address.

Summaries are paraphrased with links to the original sources. Not legal advice.
